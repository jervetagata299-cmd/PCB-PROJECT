# PCB-PROJECT
Overview
This project is a custom ESP32 Development Shield designed to provide easy access to ESP32 GPIO pins through organized header connectors. The shield includes power regulation, indicator LEDs, sensor interface headers, and expansion ports for rapid prototyping and embedded system development.
Features
Compatible with ESP32 DevKit V1
GPIO breakout headers for easy connections
Dedicated 3.3V and 5V power rails
On-board power indicator LED
Voltage regulator circuit for stable operation
Sensor and peripheral expansion connectors
EasyEDA schematic and PCB design files included
Ready for PCB fabrication through JLCPCB and other manufacturers
Hardware Components
ESP32 DevKit V1
AMS1117-3.3V Voltage Regulator
Power Indicator LED
Current Limiting Resistor
Ceramic and Electrolytic Capacitors
Male/Female Pin Headers
Barrel Jack Power Input
Power Switch
